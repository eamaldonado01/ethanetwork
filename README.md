Ethanetwork is a social media site. Visit it at [https://ethanetwork.com].

You can create your own profile using your Google account, or use the designated guest account with no sign-in!

Technical Details

- Built with Next.js and React using TypeScript
- GraphQL API powered by Apollo Server
- PostgreSQL database managed through Prisma
- Auth0 for authentication
- Socket.IO with Redis for real-time updates
- Tailwind CSS for styling
- Jest and Cypress for testing
- Docker for containerizing the application
- Infrastructure managed with Terraform
- Deployed on AWS Fargate for scalable containers
- Continuous integration handled via GitHub Actions

Social Features

- Global feed of recent and popular posts
- Create posts with text and optional images and gifs
- Like and comment on posts
- Follow or unfollow other users
- Search for people on the platform
- Update your profile with a bio, links, and avatar
